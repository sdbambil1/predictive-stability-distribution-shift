# Data

## Main empirical dataset

Place the file `Loan_default.csv` in this folder before running the manuscript.

Expected fingerprint:

- Rows: 255,347
- SHA-256: `1d7556a9071e7f9e872dc05a0cad174229fb1164b1cf3470ad35eed195c24278`

The manuscript identifies the source as the public **Loan Default Dataset** by M Yasser H on Kaggle.
The main CSV is intentionally not redistributed in this package; obtain it from the original source
and verify the checksum above.

## Separate stress-test data

`New_Loan_Validation_Data.csv` is described in the original package as a synthetic validation/stress-test file. It is not an external real-world validation cohort. Row-level validation data are omitted from this public repository. Obtain the project input separately before running the empirical renderer.
